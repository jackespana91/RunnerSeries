# Runnerz artwork preview

![Runnerz city-selection screen](Runnerz-City-Selection.png)

## Play the current build

1. Download [Runnerz-Playable-Demo.zip](Runnerz-Playable-Demo.zip?raw=1).
2. Extract the ZIP on your computer.
3. Open `Runnerz-Demo.html` in Chrome, Edge, Firefox or Safari.
4. Choose a city and press **RUN**.

This is a self-contained play-money demo. It includes the five city covers,
painted crossing characters across the other four cities, and the latest New
York pass with three painted obstacles and six shared pedestrians. The
remaining city artwork is still in progress. No Magnific processing has been
applied. The build succeeded; the latest artwork bindings still need a
playthrough. The screenshot above shows the city-selection screen.

The ZIP includes third-party notices and start instructions. GitHub's code
viewer does not run the game: download and extract the ZIP first.
